# Problem Statement

## Problem Statement
Students learning problem-solving and Python programming often need a hands-on way to practice core algorithms — number pattern checks, number theory operations, and array/matrix techniques — rather than just reading about them. There is a need for a single, organized application that brings these algorithms together in one place for learning, practice, and quick reference.

## Scope of the Project
This project implements a console-based, menu-driven Python application covering three major algorithmic areas: number patterns and sequences, number theory and factoring methods, and matrix/array operations. It is intended as an academic demonstration of applying problem-solving concepts using Python, not a production-scale software system.

## Target Users
- CSE/Programming students learning algorithmic problem solving
- Anyone wanting a quick reference tool to test number and array-based algorithms

## High-Level Features
- Check Armstrong numbers, palindromes, compute digit sums, Fibonacci sequence, and factorial
- Perform number theory operations: LCM, GCD, perfect number check, prime number generation, fast exponentiation
- Perform matrix and array operations: matrix transpose, linear search, bubble sort
- Demonstrate Python data structures: Lists, Tuples, Sets, and Dictionaries

# NumCraft - Number & Pattern Problem Solving Suite

## Overview
NumCraft is an interactive, menu-driven Python application that implements core problem-solving algorithms covering number patterns, number theory, and array/matrix operations. It was built as a CSE academic project to demonstrate fundamental algorithms and data structure techniques through a clean, modular codebase.

## Features
- **Number Patterns & Sequences:** Armstrong Number check, Palindrome check, Sum of Digits, Fibonacci Sequence, Factorial
- **Number Theory Lab:** LCM, GCD, Perfect Number checker, Prime Number generator, Fast Power computation
- **Matrix & List Operations:** Matrix Transpose, Linear Search, Bubble Sort, List/Tuple/Set/Dictionary demonstrations
- Simple, interactive menu-driven interface
- Input validation and error handling

## Technologies/Tools Used
- Python 3.x
- VS Code
- Git & GitHub for version control
